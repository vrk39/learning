<Flashcard
  question="What is Encapsulation in Object-Oriented Programming and how is it implemented in Java?"
  answer="* Definition: The wrapping up of data (variables) and code (methods) into a single unit, hiding the internal state from direct external access.
* Implementation: Achieved by declaring class variables as `private` and providing public `getter` and `setter` methods.
* Benefits: Allows validation filtering inside setter methods and protects object state consistency."
/>

<Flashcard
  question="What are Class and Object in Java?"
  answer="* Class: A blueprint, template, or prototype from which objects are created, defining variables and methods common to all objects of one type.
* Object: An instance of a class that has state (fields), behavior (methods), and a unique identity occupying physical memory."
/>

<Flashcard
  question="What is Abstraction in Object-Oriented Programming and how is it achieved in Java?"
  answer="* Definition: Abstraction is the concept of hiding implementation details and showing only essential features to the user.
* Implementation: Achieved in Java using abstract classes (0 to 100% abstraction) and interfaces (100% total abstraction).
* Purpose: Focuses on what an object does instead of how it does it, reducing code complexity and dependency."
/>

<Flashcard
  question="What is Inheritance in Java and what are its primary types and benefits?"
  answer="* Definition: A mechanism where one class acquires the properties (fields) and behaviors (methods) of another class using the 'extends' keyword.
* Types Supported: Single, Multilevel, and Hierarchical inheritance are fully supported for classes.
* Benefits: Promotes code reusability and establishes a natural hierarchical relationship between parent and child classes."
/>

<Flashcard
  question="What is Polymorphism and what is the difference between compile-time and runtime polymorphism?"
  answer="* Definition: Polymorphism means 'many forms', allowing a single action or method to behave differently based on the object or input context.
* Compile-time Polymorphism: Achieved via method overloading (static binding resolved by the compiler).
* Runtime Polymorphism: Achieved via method overriding (dynamic binding resolved at runtime based on the actual object instance)."
/>
