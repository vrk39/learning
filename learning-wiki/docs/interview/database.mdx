<Flashcard
  question="What are the different types of SQL Joins and how do they function?"
  answer="* Inner Join: Returns records that have matching values in both tables.
* Left Outer Join: Returns all records from the left table, and the matched records from the right table (with NULLs if no match).
* Right Outer Join: Returns all records from the right table, and the matched records from the left table (with NULLs if no match).
* Full Outer Join: Returns all records when there is a match in either left or right table.
* Cross Join: Matches every row of the first table with every row of the second table.
* Self Join: Joins a table with itself using table aliases."
/>

<Flashcard
  question="What are DDL, DML, and DCL commands in SQL with examples?"
  answer="* DDL (Data Definition Language): Used to create and modify database object structures (e.g., CREATE, ALTER, DROP, TRUNCATE, RENAME).
* DML (Data Manipulation Language): Used to retrieve, store, modify, and delete data (e.g., INSERT, UPDATE, DELETE, MERGE).
* DCL (Data Control Language / Transaction Control): Used to manage permissions and transactions (e.g., COMMIT, ROLLBACK, SAVEPOINT)."
/>

<Flashcard
  question="What are the differences between DELETE, TRUNCATE, and DROP commands in SQL?"
  answer="* DELETE: A DML command that removes specific rows using a WHERE clause, logs each row deletion, can be rolled back, and fires triggers.
* TRUNCATE: A DDL command that removes all rows from a table quickly by locking the table, cannot use a WHERE clause, and cannot be rolled back easily.
* DROP: A DDL command that completely removes the table structure, indexes, and privileges from the database."
/>

<Flashcard
  question="What are the key differences between DML and DDL commands in SQL?"
  answer="* Purpose: DDL is used to create and modify the schema structure, whereas DML is used to populate, retrieve, and manipulate data within tables.
* Scope: DDL statements affect entire tables, while DML commands affect one or more rows.
* Transaction Control: DDL commands are auto-committed and cannot be rolled back, whereas DML commands are not auto-committed and can be rolled back."
/>

<Flashcard
  question="How do you find the nth highest salary using SQL queries?"
  answer="* Using LIMIT/OFFSET: SELECT salary FROM employee ORDER BY salary DESC LIMIT 1 OFFSET n-1;
* Using Correlated Subquery: SELECT salary FROM employee e1 WHERE (SELECT COUNT(salary) FROM employee e2 WHERE e2.salary > e1.salary) = n-1;
* Using Window Functions: SELECT salary FROM (SELECT salary, DENSE_RANK() OVER (ORDER BY salary DESC) as rnk FROM employee) e WHERE rnk = n;"
/>

<Flashcard
  question="What are the common strategies to find duplicate records in a SQL database?"
  answer="* Using GROUP BY and HAVING: SELECT column_name, COUNT(*) FROM table_name GROUP BY column_name HAVING COUNT(*) > 1;
* Using Self Joins or Window Functions (like ROW_NUMBER() partitioned by duplicate candidate columns) to identify and delete or filter duplicate rows."
/>

<Flashcard
  question="Can a table have a Primary Key that also acts as a Foreign Key in the same table?"
  answer="* Yes: A column or set of columns in a table can simultaneously serve as part of the primary key and act as a foreign key referencing another record within the same table.
* Use Case: Commonly used in hierarchical self-referencing relationships, such as an employee table where an employee ID is the primary key and also serves as the manager ID pointing back to the same table."
/>

<Flashcard
  question="What is a View in a database and what is its purpose?"
  answer="* Definition: A view is a virtual table based on the result-set of an SQL statement.
* Purpose: Simplifies complex queries, provides security by restricting direct access to underlying table columns, and presents customized data perspectives to users."
/>

<Flashcard
  question="What are the differences between a SQL Database and a general RDBMS?"
  answer="* RDBMS: A Relational Database Management System is the underlying software program used to store, manage, query, and retrieve data structured in relational tables.
* SQL: Structured Query Language is the programming language utilized to interact with, query, and manage data within an RDBMS."
/>

<Flashcard
  question="What is a database Cursor and what are its types?"
  answer="* Definition: A temporary work area or pointer that stores data and result sets resulting from data manipulation, holding only one row at a time.
* Implicit Cursors: Declared automatically by the database engine when DML statements (INSERT, UPDATE, DELETE) are executed.
* Explicit Cursors: Declared explicitly by the programmer when SELECT statements return more than one row."
/>

<Flashcard
  question="What are the differences between UNION, UNION ALL, INTERSECT, and MINUS set operations?"
  answer="* UNION: Combines result sets of two SELECT queries and eliminates duplicate rows.
* UNION ALL: Same as UNION, but retains all duplicate rows.
* INTERSECT: Returns only the records that are common to both SELECT queries.
* MINUS: Returns records from the first query that are not present in the second query's result set."
/>

<Flashcard
  question="What are the common Constraints used in SQL and what are their purposes?"
  answer="* NOT NULL: Restricts NULL values from being inserted into a column.
* CHECK: Verifies that all values in a field satisfy a specific condition.
* DEFAULT: Automatically assigns a default value if none is specified for the field.
* UNIQUE: Ensures all values inserted into a field are unique.
* PRIMARY KEY: Uniquely identifies each record in a table.
* FOREIGN KEY: Ensures referential integrity for a record relative to another table."
/>

<Flashcard
  question="What are the main Clauses used in SQL and how do they function?"
  answer="* WHERE: Filters records based on specific necessary conditions.
* ORDER BY: Sorts records based on specified fields in ascending (ASC) or descending (DESC) order.
* GROUP BY: Groups records with identical data, often used with aggregation functions to produce summarized results.
* HAVING: Filters aggregated records in combination with GROUP BY (unlike WHERE which cannot filter aggregated results)."
/>

<Flashcard
  question="What are the differences between CHAR and VARCHAR data types in SQL?"
  answer="* CHAR: Fixed-length character data type; pads spaces to fill the specified length if the input string is shorter.
* VARCHAR: Variable-length character data type; stores only the actual characters entered without trailing padding spaces, saving space."
/>

<Flashcard
  question="What are the roles of the DML Compiler and the DDL Interpreter in a database management system?"
  answer="* DML Compiler: Translates DML query statements into low-level instructions understood by the Query Evaluation Engine.
* DDL Interpreter: Interprets DDL statements and records the generated instructions into the metadata table."
/>

<Flashcard
  question="How are the terms 'Record', 'Field', and 'Table' defined in the context of a database?"
  answer="* Record: A collection of values or fields representing a specific entity (e.g., an employee).
* Field: An area within a record reserved for a specific piece of data (e.g., Employee ID).
* Table: A structured collection of records of a specific type."
/>
