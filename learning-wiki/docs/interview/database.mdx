<Flashcard
  question="What are DDL, DML, and DCL commands in SQL with examples?"
  answer="* DDL (Data Definition Language): Used to create and modify database object structures (e.g., CREATE, ALTER, DROP, TRUNCATE, RENAME)[cite: 1].
* DML (Data Manipulation Language): Used to retrieve, store, modify, and delete data (e.g., INSERT, UPDATE, DELETE, MERGE)[cite: 1].
* DCL (Data Control Language / Transaction Control): Used to manage permissions and transactions (e.g., COMMIT, ROLLBACK, SAVEPOINT)[cite: 1]."

<Flashcard
  question="What are the differences between DELETE, TRUNCATE, and DROP commands in SQL?"
  answer="* DELETE: A DML command that removes specific rows using a WHERE clause, logs each row deletion, can be rolled back, and fires triggers[cite: 1].
* TRUNCATE: A DDL command that removes all rows from a table quickly by locking the table, cannot use a WHERE clause, and cannot be rolled back easily[cite: 1].
* DROP: A DDL command that completely removes the table structure, indexes, and privileges from the database[cite: 1]."
/>

<Flashcard
  question="What are the key differences between DML and DDL commands in SQL?"
  answer="* Purpose: DDL is used to create and modify the schema structure, whereas DML is used to populate, retrieve, and manipulate data within tables[cite: 1].
* Scope: DDL statements affect entire tables, while DML commands affect one or more rows[cite: 1].
* Transaction Control: DDL commands are auto-committed and cannot be rolled back, whereas DML commands are not auto-committed and can be rolled back[cite: 1]."
/>

  question="How do you find the nth highest salary using SQL queries?"

<Flashcard
  question="What are the differences between UNION, UNION ALL, INTERSECT, and MINUS set operations?"
  answer="* UNION: Combines result sets of two SELECT queries and eliminates duplicate rows[cite: 1].
* UNION ALL: Same as UNION, but retains all duplicate rows[cite: 1].

* MINUS: Returns records from the first query that are not present in the second query's result set[cite: 1]."
