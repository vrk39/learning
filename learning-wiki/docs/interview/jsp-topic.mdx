<Flashcard
  question="What is the JSP lifecycle and what are its core phases?"
  answer="* Translation Phase: The JSP container translates the JSP file into a servlet source (.java file)[cite: 1].
* Compilation Phase: The container compiles the servlet source into a Java bytecode class file (.class)[cite: 1].
* Initialization Phase: The jspInit() method is called once when the JSP servlet instance is created[cite: 1].
* Execution Phase: The _jspService() method handles incoming client requests and generates responses[cite: 1].
* Destruction Phase: The jspDestroy() method is invoked when the JSP is about to be taken out of service[cite: 1]."

  question="How can you prevent direct access to JSP files in a Java web application?"
  answer="* WEB-INF Directory: Place JSP files inside the WEB-INF folder because resources located under WEB-INF cannot be accessed directly by clients via direct URL requests[cite: 1].
* Controller Routing: Force all requests to go through a controller servlet or MVC framework which forwards to the JSP internally[cite: 1]."

<Flashcard
  question="How do you write comments, scriptlets, expressions, and declarations in JSP?"
  answer="* Comments: HTML comments <!-- comment --> are sent to the client, whereas JSP comments <%-- comment --%> are hidden from the client[cite: 1].
* Scriptlet: <% java code %> embeds arbitrary Java code executed during request processing[cite: 1].
* Expression: <%= expression %> evaluates an expression and outputs the result directly to the response[cite: 1].
* Declaration: <%! declarations %> declares class-level variables and methods inside the generated servlet class[cite: 1]."
/>

<Flashcard
  question="What are the implicit objects available in JSP?"
  answer="* Definition: Objects created by the web container that are automatically available for use within JSP scriptlets and expressions[cite: 1].
* Core Objects: request, response, session, application, out, config, pageContext, page, and exception[cite: 1]."
/>

<Flashcard
  question="How do you handle exceptions in JSP pages?"
  answer="* isErrorPage Attribute: Designate an error-handling JSP page by setting <%@ page isErrorPage='true' %>[cite: 1].
* errorPage Attribute: Point a vulnerable or standard JSP page to the error handler using <%@ page errorPage='error.jsp' %>[cite: 1].
* Exception Object: Access the thrown exception using the implicit 'exception' object on the designated error page[cite: 1]."
/>

<Flashcard
  question="Which methods can you override in a JSP lifecycle?"
  answer="* jspInit(): Overridden inside declarations (`<%! ... %>`) to perform custom initialization tasks when the JSP servlet instance is first created.
* jspDestroy(): Overridden to execute clean-up activities when the JSP servlet is being taken out of service.
* Note: The primary request handling method `_jspService()` cannot be overridden directly as it is automatically generated by the JSP container."
/>

<Flashcard
  question="What are the differences between the Include Directive and the Include Action in JSP?"
  answer="* Include Directive (`<%@ include file='...' %>`): A translation-time inclusion that copies the raw content of the target file into the main JSP file before compilation.
* Include Action (`<jsp:include page='...' />`): A request-time inclusion that processes the target page dynamically and includes its output response during request execution."
/>

<Flashcard
  question="How can you disable scriptlets in a JSP page?"
  answer="* Deployment Descriptor: Scriptlets can be disabled globally or per-file in `web.xml` using the `<jsp-property-group>` element.
* Configuration Tag: Setting `<scripting-invalid>true</scripting-invalid>` inside the property group causes the compiler to reject any embedded scriptlets (`<% ... %>`) with a translation error, encouraging cleaner MVC tag library usage."
/>

<Flashcard
  question="What is JSTL and what are its core modules/libraries?"
  answer="* Definition: JSTL (JavaServer Pages Standard Tag Library) is a collection of useful custom tags that encapsulate core functionality common to many JSP pages, eliminating the need for scriptlets.
* Core Libraries: Includes Core (conditionals, loops), Formatting (locales, dates, numbers), SQL (database access, deprecated in modern MVC), XML (parsing/transform), and Functions (string manipulation)."
/>

<Flashcard
  question="How do you declare and use Java methods or variables within a JSP page?"
  answer="* Declarations (`<%! ... %>`): Used to declare class-level member variables and methods that persist across requests within the servlet class scope.
* Distinction: Regular scriptlets (`<% ... %>`) place code inside the local `_jspService()` method, whereas declarations place code outside it at the class level."
