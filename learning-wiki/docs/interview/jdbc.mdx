<Flashcard
  question="What are the step-by-step procedures to create a JDBC connection and execute queries?"
  answer="* Driver Registration: Register the database driver implementation class with java.sql.DriverManager using Class.forName().
* Connection Establishment: Open a session to the database by calling DriverManager.getConnection(), which returns a Connection object.
* Statement Creation: Create a Statement, PreparedStatement, or CallableStatement object from the connection to submit SQL queries.
* Execution & Result Handling: Execute updates via executeUpdate() or queries via executeQuery(), then process results using the ResultSet interface."
/>

<Flashcard
  question="How do you run a stored procedure using JDBC?"
  answer="* CallableStatement: Use a CallableStatement object to invoke stored procedures.
* Preparation: Obtain the CallableStatement object by calling the Connection.prepareCall() method with the procedure syntax (e.g., '{call myprocedure(?,?)}').
* Parameter Binding: Bind parameters using index-based setter methods (e.g., setInt(), setDouble()).
* Execution: Execute the stored procedure by invoking the execute() method."
/>
