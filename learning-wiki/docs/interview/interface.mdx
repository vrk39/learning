<Flashcard
  question="What are the main differences between an abstract class and an interface in Java?"
  answer="* Method Types: An interface can only have abstract methods (plus default and static methods from Java 8), whereas an abstract class can have both abstract and non-abstract methods[cite: 1].
* Variables: Interface variables are implicitly public, static, and final, while abstract classes can contain non-final and non-static variables[cite: 1].
* Inheritance Syntax: Interfaces are implemented using 'implements', while abstract classes are extended using 'extends'[cite: 1]."

<Flashcard
  question="What is a marker interface in Java and what is its purpose?"
  answer="* Definition: An interface that contains no methods or constants inside it[cite: 1].
* Purpose: Provides run-time type information (RTTI) about objects so the compiler and JVM have additional context[cite: 1].
* Example: Used to signal special behavior, such as serializability or deletability[cite: 1]."

  question="How do you create and use a custom marker interface in Java?"
  answer="* Creation: Declare an empty interface without any methods or constants (e.g., public interface Deletable {})[cite: 1].
* Implementation: Have a target entity class implement the marker interface (e.g., class Entity implements Deletable {})[cite: 1].

<Flashcard
  question="What is an abstract class in Java and why is it used?"
  answer="* Definition: A class declared with the 'abstract' keyword that can contain both abstract and concrete methods[cite: 1].
* Instantiation: An instance of an abstract class cannot be directly created[cite: 1].
