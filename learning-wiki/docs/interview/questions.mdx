### 1. Collection Topic

<Flashcard
  question="How do you iterate or fetch data from a HashMap using EntrySet?"
  answer="You can iterate over a map using a for-each loop on map.entrySet() to access the key-value pairs directly."
/>

<Flashcard
  question="What is the difference between a List and a Set?"
  answer="A List allows duplicate elements and maintains insertion order, whereas a Set contains only unique elements and does not guarantee insertion order."
/>

<Flashcard
  question="What is the difference between ArrayList and TreeSet?"
  answer="ArrayList is an ordered collection backed by a dynamic array that allows duplicates. TreeSet is a sorted collection backed by a TreeMap that contains unique elements and maintains ascending order by default."
/>

<Flashcard
  question="When should you use Vector instead of ArrayList?"
  answer="Vector is synchronized, meaning only one thread can access the code at a time (thread-safe). ArrayList is not synchronized, meaning multiple threads can work on it simultaneously. Use Vector in multi-threaded environments."
/>

<Flashcard
  question="How does a HashMap work internally and what is the index generation formula?"
  answer="HashMap internally uses an array and a linked list data structure. The position of the bucket is identified using the formula: hashcode(Key) &amp; (n-1)."
/>

<Flashcard
  question="What is the difference between Collection and Collections in Java?"
  answer="Collection is an interface at the root of the framework, while Collections is a utility class providing static methods to operate on collections."
/>

<Flashcard
  question="What is the difference between Comparable and Comparator?"
  answer="Comparable provides a single natural sorting sequence (using compareTo), modifying the original class. Comparator provides multiple custom sorting sequences (using compare) in a separate class."
/>

<Flashcard
  question="What is the difference between a Map and a Set?"
  answer="A Map stores data in key-value pairs where keys must be unique. A Set stores unique standalone values/elements."
/>

<Flashcard
  question="What is an Iterator?"
  answer="An interface used to iterate over collections in Java to retrieve elements sequentially."
/>

<Flashcard
  question="What are the ways to iterate data in a Collection?"
  answer="The common methods are: Iterator, traditional for loop, for-each loop, and Java 8 stream/forEach methods."
/>

<Flashcard
  question="What is the difference between Fail-Fast and Fail-Safe Iterators?"
  answer="Fail-Fast iterators throw a ConcurrentModificationException if the collection is modified during iteration. Fail-Safe iterators operate on a cloned copy, preventing the exception in such scenarios."
/>

<Flashcard
  question="Why use ConcurrentHashMap from the concurrent package over HashMap?"
  answer="HashMap is fast but not thread-safe. ConcurrentHashMap provides thread safety, allowing multiple threads to read concurrently and locking only specific segments for updates."
/>

<Flashcard
  question="When and why should you use LinkedHashMap?"
  answer="LinkedHashMap provides the quick insertion, search, and deletion of a HashMap but additionally maintains the insertion order of elements."
/>

<Flashcard
  question="What is the initial default capacity of a HashMap?"
  answer="The initial default capacity is 16."
/>

<Flashcard
  question="What is the threshold in a HashMap?"
  answer="When the number of key-value pairs exceeds the threshold value, the HashMap is automatically resized."
/>

<Flashcard
  question="How do you convert an Array to a List or Set?"
  answer="To List: Lists.newArrayList(array), Arrays.stream(array).collect(Collectors.toList()), Collections.addAll(list, array), or Arrays.asList(array). To Set: iterating and adding, new HashSet&lt;&gt;(Arrays.asList(array)), Collections.addAll(set, array), or Streams."
/>

<Flashcard
  question="What is the equals and hashCode contract?"
  answer="If two objects are equal according to the equals() method, they must generate the exact same integer result when hashCode() is called."
/>

<Flashcard
  question="How do you store user-defined classes in TreeSet, HashSet, or TreeMap?"
  answer="You must override hashCode() and equals() for HashSet/HashMap. For TreeSet/TreeMap, the class must implement Comparable or you must provide a Comparator, otherwise it throws exceptions."
/>

<Flashcard
  question="How do you create an immutable user-defined class?"
  answer="Declare the class as final, make data members private and final, initialize via a parameterized constructor performing a deep copy, and return deep copies in getter methods."
/>

<Flashcard
  question="What is the Collection Hierarchy?"
  answer="The Iterable interface is the root, extended by the Collection interface, which is further extended by List, Queue, and Set. Map is part of the framework but does not inherit from Collection."
/>

<Flashcard
  question="Why does HashMap internally use both Array and Linked List data structures?"
  answer="It uses an array for quick indexed access (buckets) and a linked list (or tree) inside each bucket to handle hash collisions when multiple keys produce the same index."
/>

<Flashcard
  question="What are the key characteristics of IdentityHashMap?"
  answer="It implements the Map interface, uses reference equality (k1==k2) instead of equals() for comparing keys, is not synchronized, and has a default size of 21."
/>

<Flashcard
  question="What are the characteristics of a Hashtable?"
  answer="It is an array of lists (buckets), contains unique elements, does not allow null keys/values, is synchronized, and has a default capacity of 11 with a load factor of 0.75."
/>

<Flashcard
  question="What is a WeakHashMap?"
  answer="It maintains insertion order, holds weak references to keys (keys are automatically removed when their external reference scope is lost), and does not implement Cloneable or Serializable."
/>

<Flashcard
  question="What is the role of the GC (Garbage Collection) thread?"
  answer="It automatically destroys unused and unreachable objects from memory."
/>

<Flashcard
  question="What is the finalize method?"
  answer="It is called always before every object is garbage collected, allowing developers to execute clean-up activities."
/>

<Flashcard
  question="What is CopyOnWriteArrayList?"
  answer="It is a thread-safe version of ArrayList that creates a cloned copy for every update operation. It is best used when read operations are frequent. Its iterator cannot perform remove/add/set operations."
/>

<Flashcard
  question="What is ConcurrentHashMap?"
  answer="It is a thread-safe map that divides objects into segments (default concurrency level 16). Multiple threads can read without locking, but updates lock the specific segment. Null keys/values are not allowed."
/>

<Flashcard
  question="What is the difference between HashSet and TreeSet?"
  answer="HashSet does not maintain any order, allows null values, and relies on hashing. TreeSet maintains ascending order, does not allow null values (throws NullPointerException via compareTo), and relies on a tree structure. Both are non-synchronized."
/>

<Flashcard
  question="Compare ArrayList and LinkedList."
  answer="ArrayList uses a dynamic array (better for sorting/accessing, stores contiguously). LinkedList uses a doubly linked list (better for manipulation/insertions, stores non-contiguously)."
/>

<Flashcard
  question="What is the specific feature of LinkedHashSet?"
  answer="It maintains the insertion order of elements while ensuring uniqueness."
/>

<Flashcard
  question="What is the difference between an ArrayList and an Array?"
  answer="An Array is a fixed-size data structure that can contain primitive and non-primitive values. An ArrayList increases its size dynamically and can only contain objects."
/>

### 2. Normal Question Topic

<Flashcard
  question="What is a Wrapper class?"
  answer="A class that converts primitives into objects and vice versa. It is required because Java synchronization, the java.util package, and the Collection Framework deal strictly with objects."
/>

<Flashcard
  question="What are the sizes and default values of Java primitive data types?"
  answer="boolean (1 bit, false), char (16 bit, \\u0000), byte (8 bit, 0), short (16 bit, 0), int (32 bit, 0), float (32 bit, 0.0), long (64 bit, 0), double (64 bit, 0.0). String and Arrays are non-primitive."
/>

<Flashcard
  question="What is the difference between '==' and the equals() method?"
  answer="The '==' operator checks reference equality (memory address), whereas the equals() method evaluates content comparison (actual values)."
/>

<Flashcard
  question="What is a deployment descriptor (web.xml)?"
  answer="It is an XML file (root &lt;web-app&gt;) used by the web server to map URL requests to specific servlet classes using &lt;servlet&gt; and &lt;servlet-mapping&gt; configurations."
/>

<Flashcard
  question="What is the use of the final keyword?"
  answer="It is a non-access specifier that restricts modification: a final variable cannot be changed, a final method cannot be overridden, and a final class cannot be inherited."
/>

<Flashcard
  question="What is the 'finally' block?"
  answer="Used with a try/catch block, it guarantees code execution (like resource deallocation) even if an exception is thrown before control transfers back."
/>

<Flashcard
  question="What is the 'finalize' method?"
  answer="A method called by the Garbage Collector just before destroying an object to perform clean-up activities. It can be overridden but is not a reserved keyword."
/>

<Flashcard
  question="What is the difference between static and non-static variables?"
  answer="Static variables are shared among all instances of a class. Non-static variables belong strictly to a specific instance of a class."
/>

<Flashcard
  question="What is the difference between isInstance() and instanceof?"
  answer="instanceof is an operator checked at compile time, whereas isInstance() is a method checked dynamically at runtime."
/>

<Flashcard
  question="What is the difference between a shallow copy and a deep copy?"
  answer="A shallow copy duplicates fields, but nested object references still point to original instances. A deep copy creates entirely independent copies of all nested objects."
/>

<Flashcard
  question="What is object cloning?"
  answer="The creation of an exact copy of an object, initializing a new instance with the exact contents of the current object's fields."
/>

<Flashcard
  question="What is the difference between ClassNotFoundException and NoClassDefFoundError?"
  answer="ClassNotFoundException occurs at runtime when trying to load a class via Class.forName(). NoClassDefFoundError occurs when a class was present at compile time but is missing at runtime."
/>

<Flashcard
  question="Why does an IndexOutOfBoundException occur?"
  answer="It occurs when attempting to access an index of an array or collection that is either negative or greater than/equal to its size."
/>

<Flashcard
  question="How do you create an immutable class with nested structures like Maps?"
  answer="Make the class final, variables private final, initialize collections using deep copies within the parameterized constructor, and return deep copies in getter methods."
/>

<Flashcard
  question="What is a Covariant return type?"
  answer="It allows an overriding method in a child class to have a different return type, provided the new return type is a valid sub-type of the parent's return type."
/>

<Flashcard
  question="What is an enum in Java?"
  answer="An enumeration used to represent a group of named constants known at compile time. Enums can also contain variables, methods, and constructors."
/>

<Flashcard
  question="What does load-on-startup in web.xml do?"
  answer="A positive value loads and pre-initializes the servlet at deployment or server startup in ascending order. A negative value loads it lazily upon the first request."
/>

<Flashcard
  question="How does static synchronization work?"
  answer="It acquires a class-level lock. Static and non-static synchronized methods can run simultaneously without blocking each other, but multiple threads cannot access static synchronized methods concurrently."
/>

<Flashcard
  question="How does non-static synchronization work?"
  answer="It acquires an object-level lock, restricting concurrent access to the specific instance's synchronized methods."
/>

<Flashcard
  question="What is the purpose of System.gc()?"
  answer="It suggests that the JVM expend effort toward recycling unused objects to make memory available for quick reuse."
/>

<Flashcard
  question="How do you expire a session after a specific time interval?"
  answer="You can define a global timeout in the servlet container or override it per application using the &lt;session-timeout&gt; element inside &lt;session-config&gt; in web.xml."
/>

<Flashcard
  question="What are the Java access modifiers and their scope?"
  answer="Private (class only), Default (package only), Protected (package and outside via child class), Public (everywhere)."
/>

<Flashcard
  question="How is Java heap classified?"
  answer="Memory is broadly classified into Stack memory and Heap memory allocations."
/>

<Flashcard
  question="How can you prevent an object from being garbage collected?"
  answer="By increasing heap memory, storing its reference in a static field (Singleton pattern), or overriding finalize() to resurrect the reference."
/>

<Flashcard
  question="What is the purpose of web.xml?"
  answer="It defines mappings between URL paths and servlets, allowing the web server to identify and call the appropriate class method for incoming requests."
/>

<Flashcard
  question="How do you convert JSON to an Object or vice versa?"
  answer="Using the Jackson library's ObjectMapper. Use writeValueAsString() or writeValue() to map Object to JSON, and readValue() or readTree() to map JSON to Object."
/>

<Flashcard
  question="What interface changes were introduced in Java 8?"
  answer="Java 8 introduced the ability for interfaces to contain default methods and static methods with concrete implementations."
/>

<Flashcard
  question="What is the Java Persistence API (JPA)?"
  answer="JPA is a Java specification for accessing, persisting, and managing data between Java objects and a relational database. ORM tools implement JPA."
/>

<Flashcard
  question="What is the difference between Loose Coupling and Tight Coupling?"
  answer="Tight coupling means classes depend directly on each other's concrete implementations. Loose coupling uses interfaces to keep classes independent, interacting only via exposed capabilities."
/>

<Flashcard
  question="What are Generics in Java?"
  answer="Parameterized types providing compile-time type safety. They ensure collections only hold defined types, eliminating the need for runtime type casting."
/>

<Flashcard
  question="What is Non-Generic programming?"
  answer="Using structures that can hold any type of data without compile-time safety, requiring individual type casting at every retrieval checked at runtime."
/>

<Flashcard
  question="What is Serialization?"
  answer="The process of converting the state of an object into a byte stream so it can be persisted to a file/disk or sent over a network."
/>

<Flashcard
  question="What is Deserialization?"
  answer="The reverse process of serialization, where a byte stream is used to recreate the actual Java object back in memory."
/>

<Flashcard
  question="What is Encapsulation, and what are Static vs Dynamic binding?"
  answer="Encapsulation hides variables via private access and exposes them through getter/setter methods. Static binding resolves method calls at compile time (private, final, static), while dynamic binding resolves at runtime based on object type."
/>

<Flashcard
  question="What are the types of inner classes?"
  answer="Member inner class (requires outer object instance), Static inner class (accessed via outer class name without instance), and Anonymous inner class (inline declaration)."
/>

<Flashcard
  question="How does a ClassLoader work and what are its types?"
  answer="It loads class files into memory. Types include Bootstrap (loads core Java API), Extension (loads extension directory), and System (loads application classpath)."
/>

<Flashcard
  question="What are the SOLID principles?"
  answer="Single Responsibility, Open-Closed (open for extension, closed for modification), Liskov Substitution, Interface Segregation, and Dependency Inversion."
/>

### 3. String, Buffer, and Builder Topic

<Flashcard
  question="Why is the String class immutable in Java?"
  answer="For Security (protecting network/DB parameters), Synchronization (inherently thread-safe), Caching (allows String pool optimization), and Class loading safety."
/>

<Flashcard
  question="What is the difference between StringBuilder and StringBuffer?"
  answer="StringBuilder is non-synchronized, not thread-safe, but highly efficient. StringBuffer is synchronized, thread-safe, but less efficient."
/>

<Flashcard
  question="What is the String Constant Pool?"
  answer="It is a memory area containing symbolic references used to locate actual string objects, preventing duplicate string allocation."
/>

<Flashcard
  question="What is the difference between creating a String using a literal vs the 'new' keyword?"
  answer="String literals are optimized and cached in the String pool. Using 'new' forces the creation of a brand-new object in the heap memory regardless of pool contents."
/>

<Flashcard
  question="What is the difference between replace() and replaceAll() in Strings?"
  answer="replace() swaps all occurrences of an old character sequence with a new one. replaceAll() performs replacements based on regular expressions. replaceFirst() replaces only the first occurrence."
/>

<Flashcard
  question="What are the final methods of the Object class?"
  answer="Built-in final methods include wait(), notify(), notifyAll(), and getClass()."
/>

<Flashcard
  question="How does the equals() method behave in StringBuilder?"
  answer="StringBuilder does not override the Object class's equals() method, meaning it compares memory references instead of actual string content."
/>

### 6. Exception Topic

<Flashcard
  question="What is an Exception in Java?"
  answer="An event that occurs during program execution that disrupts the normal flow of instructions."
/>

<Flashcard
  question="How do you handle Checked and Unchecked exceptions?"
  answer="Checked exceptions are predicted at compile time and must be handled using try-catch blocks or declared with throws. Unchecked exceptions extend RuntimeException and are checked only at runtime."
/>

<Flashcard
  question="What is the difference between Error and Exception?"
  answer="Errors (like OutOfMemoryError) are unrecoverable and typically ignored in code, while Exceptions can be caught and handled."
/>

<Flashcard
  question="What is the difference between throw and throws?"
  answer="throw is used to explicitly throw an exception object. throws is used in a method signature to inform callers of possible exceptions that might be thrown."
/>

<Flashcard
  question="How does exception handling interact with method overriding?"
  answer="If a superclass method does not declare an exception, the subclass cannot declare a checked exception (but can declare unchecked). If it does, the subclass can declare the same or a narrower subclass exception, but never a parent exception."
/>

### 7. Multi_Thread Topic

<Flashcard
  question="What is the Life cycle of a Thread?"
  answer="A thread transitions through New, Runnable, Running, Non-Runnable (Waiting/Blocked), and Terminated/Dead states."
/>

<Flashcard
  question="What does the yield() method do?"
  answer="It is a static method that stops the currently executing thread, giving a chance to other waiting threads of the same priority."
/>

<Flashcard
  question="What does the join() method do?"
  answer="It puts the current thread on wait until the thread on which join() is called finishes executing (dies) or the specified timeout expires."
/>

<Flashcard
  question="What is the difference between Callable and Runnable?"

/>

### 8. Design Pattern Topic

<Flashcard
  question="What is the Singleton Pattern?"
  answer="It restricts the instantiation of a class and ensures only one instance exists in the JVM. Thread safety is typically achieved using double-checked locking inside the getInstance() synchronized block or by using Enums."
/>

<Flashcard
  question="What is the Factory Pattern?"
  answer="It shifts instantiation responsibility from the client to a factory class. Based on input parameters, a static factory method returns one of many subclasses sharing a common superclass."
/>

<Flashcard
  question="What is the Prototype Design pattern?"
  answer="Used when object creation is a costly affair. It provides a mechanism to copy (using java cloning) an already existing original object and modify it rather than creating it from scratch."
/>

### 9. DataBase Topic

<Flashcard
  question="What are the different types of SQL Joins?"
  answer="Cross Join (cartesian product), Inner Join (matching rows), Left Outer Join (all left + matching right), Right Outer Join (all right + matching left), Full Outer Join (all rows), Self Join (table joined with itself using aliases), and Natural Join (implicit based on matching column names)."
/>

<Flashcard
  question="What are DDL, DML, and DCL commands?"
  answer="DDL modifies schema (CREATE, ALTER, TRUNCATE, DROP). DML manipulates data (INSERT, UPDATE, DELETE, MERGE). DCL manages permissions (COMMIT, ROLLBACK, SAVEPOINT)."
/>

<Flashcard
  question="What is the difference between DDL and DML operations?"
  answer="DDL affects the whole table, is auto-committed (permanent), and declarative. DML affects specific rows, requires manual commits/rollbacks, and is imperative."
/>

<Flashcard
  question="What is the difference between DELETE, TRUNCATE, and DROP?"
  answer="DELETE uses row locks (can be filtered and rolled back). TRUNCATE uses a table lock (faster, resets schema, cannot be filtered). DROP removes the table completely from the database."
/>

<Flashcard
  question="What is the difference between UNION and UNION ALL?"
  answer="UNION combines results of SELECT statements while eliminating duplicate rows. UNION ALL combines results while retaining all duplicates."
/>

<Flashcard
  question="What do INTERSECT and MINUS do?"
  answer="INTERSECT returns only records common to both SELECT statements. MINUS returns records belonging only to the first SELECT result set, eliminating matches from the second."
/>

<Flashcard
  question="What are the SQL filter and grouping clauses?"
  answer="WHERE filters records before grouping, ORDER BY sorts results, GROUP BY aggregates identical data, and HAVING filters aggregated records after grouping."
/>
