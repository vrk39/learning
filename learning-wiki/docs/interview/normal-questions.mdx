<Flashcard
  question="What is the difference between a shallow copy and a deep copy in Java?"
  answer="* Shallow Copy: Copies all primitive fields directly. For object reference fields, only the memory references are copied, meaning changes to nested objects affect both the original and the copied object.
* Deep Copy: Creates a completely independent copy of all fields, including recursively cloning any nested objects, ensuring that modifications to the copy have zero impact on the original object."

<Flashcard
  question="How is the JVM heap memory classified?"
  answer="* Young Generation: Divided into Eden Space and two Survivor Spaces (S0, S1), where new objects are allocated and short-lived objects are cleared via minor GC.

* Metaspace / Permanent Generation: Stores class metadata, method definitions, and static variables (Metaspace replaced PermGen in Java 8 and uses native memory)."
